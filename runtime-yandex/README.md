# Тестовая версия сайта в Яндексе

Отдельный Node.js-процесс запускает существующий Worker через стандартные Request/Response.
`PostgresD1` сохраняет интерфейс запросов исходного кода, но использует PostgreSQL.
Целевые версии: Node 24, PostgreSQL 17, pg 8.16.3.

Это **изолированный предпросмотр**, не перенос рабочей базы и не переключение домена.
Запуск требует `PREVIEW_MODE=1`. Данные PostgreSQL находятся в отдельном Docker-томе
на российской ВМ; рабочие PostgreSQL, D1 и ключи Telegram не используются.
Единственные скопированные данные — уже опубликованные тексты и мероприятия.
Участники, заявки и билеты только вымышленные. Исходящие интеграции заглушены,
вебхук и расписания выключены, тестовая сеть Docker закрыта для выхода в интернет.
Предпросмотр исключён из индексации и помечен видимым предупреждением.

## Проверка

`npm ci --ignore-scripts` → `npm run test:adapter` → `npm run prepare:public`.
На российском сервере: `node runtime-yandex/test-integration.mjs` внутри контейнера.
Вход в тестовые роли доступен на `/admission`, обзор — `/preview`.
Для форм допускаются имя с префиксом «ТЕСТ», телефон +70000000000 и @demo_user.

## Перед рабочим переносом

Нужны отдельная проверка всех служебных сценариев, перенос актуальных рабочих данных
в согласованную основную российскую БД, штатные секреты и Telegram-авторизация,
единственный исполнитель расписаний, переключение публикации и проверенный возврат.
Тестовые входы и ограничения нельзя просто отключить и назвать это production.
Цены, дизайн и действующие URL основного сайта сохраняются.
