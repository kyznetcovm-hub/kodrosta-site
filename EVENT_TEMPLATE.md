# Шаблон нового мероприятия для сайта

Скопируйте, заполните и пришлите в чат — выложу на сайт.

Удобнее всего — через бота: `/menu` → «02 · Создать мероприятие» → кнопка **«➕ Добавить на сайт Код Роста»** или **«🌲 ➕ Добавить на сайт Туризм»**. Бот пришлёт этот же шаблон, а направление запомнит по кнопке — для «Туризма» строку «Категория» заполнять не нужно.

```
Дата:
Время: с — до
Место проведения (название):
Адрес:
Название мероприятия:
Категория (Обучение / Нетворкинг / Диалог с властью / Экспертиза резидентов / Семейный формат / Туризм / другое):
План участников (сколько человек хотим собрать, числом):
Описание:

Регистрация: (обычно пусто — ссылку на событие для поста бот пришлёт сам; сюда — только ссылку на Telegram-чат мероприятия, если он есть: человек увидит её после записи)
```

## Пример (по мероприятию 26 августа)

```
Дата: 26 августа
Время: 16:00 — 18:00
Место проведения: центр «Мой Бизнес»
Адрес: ул. Петербургская, 28
Название мероприятия: Практическая конференция по применению нейросетей в бизнесе
Категория: Обучение
План участников: 40
Описание: Собственники бизнеса показывают, что у них реально работает: ИИ-продавец
обработал более 30 000 заявок на Авито, автоматизация в производстве, полиграфии,
фитнесе и найме персонала. Будет и секретный спикер с противоположной позицией.

Регистрация: https://t.me/+BEeoSHbPFeVhMjVi
```

## Примечания

- Описание можно присылать длинным, маркетинговым текстом (как в примере) — я сам сокращу его под формат карточки на сайте, сохранив суть и конкретные цифры.
- Запись на любое мероприятие идёт только через форму сайта или бота — так каждая заявка попадает в бота, в «Список участников» мероприятия. Ссылка в «Регистрация» больше не заменяет форму: если указать чат, человек сначала запишется, а потом увидит кнопку «Вступить в чат мероприятия».
- После публикации бот пришлёт **ссылку для поста** вида `codrosta.club/e/<id>` — её и ставьте в посты Telegram/Instagram: по ней открывается сайт с превью этого мероприятия и сразу форма записи. Та же ссылка есть на карточке мероприятия в боте (`/menu` → мероприятия).
- **Категория «Туризм»** — мероприятие направления «Туризм Поволжья»: оно появится только на странице `codrosta.club/turizm` (на главной клуба и в общем календаре его не будет), ссылка для поста — `codrosta.club/turizm/<id>`. В списке мероприятий бота такие помечены 🌲.
- **План участников** — сколько человек хотим собрать (например, `20`). Нужен для «Офиса в кармане»: там видно «записалось / план» и сколько ещё добрать. Это не лимит — запись после достижения плана не закрывается. Можно оставить пустым и задать позже прямо в офисе, в карточке события.
- Прошедшие мероприятия сайт скрывает из «Ближайших событий» сам, ничего чистить вручную не нужно.
