# Выгрузка участников Telegram-групп + сверка с резидентами

`dump_group_members.py` заходит в Telegram под **твоим личным номером** (один раз),
берёт список участников выбранных групп и сверяет их с базой резидентов
(вкладка «вступившие» из гугл-таблицы).

Почему не через бота: Telegram **не даёт** ботам список участников группы. Это
единственный рабочий способ для уже прошедших групп.

Результаты — в папке `scripts/out/`:
- `members_<группа>.csv` — все участники (id, @username, имя, premium);
- `crossref_<группа>.csv` — те же люди с меткой `резидент` / `пригласить` / `проверить_вручную`;
- в конце работы скрипт печатает готовую строку `@ник @ник ...` для рассылки приглашений.

Файлы `kodrosta_config.json`, `kodrosta_session.session`, `residents.csv`,
папка `out/` — в `.gitignore`, в репозиторий не попадают.

## Шаги (делается один раз)

### 1. Установить библиотеку

Открой Терминал, вставь строку целиком, нажми Enter:

```
python3 -m pip install --user telethon
```

Если ответит `No module named pip` — сначала выполни `python3 -m ensurepip --user`, потом строку выше ещё раз.

### 2. Получить api_id и api_hash

1. Открой в браузере https://my.telegram.org
2. Введи свой номер телефона (тот же, что в Telegram) → в Telegram придёт код → введи его на сайте.
3. На странице нажми **API development tools**.
4. Заполни: **App title** — `kodrosta`, **Short name** — `kodrosta`, **Platform** — Desktop. Нажми **Create application**.
5. На следующей странице скопируй два значения: **App api_id** (число) и **App api_hash** (длинная строка). Держи их под рукой.

### 3. Выгрузить вкладку «вступившие» в файл

1. Открой гугл-таблицу с резидентами.
2. Внизу нажми вкладку **«вступившие»**.
3. Меню **Файл → Скачать → Файл CSV (.csv)** — файл упадёт в «Загрузки».
4. Вставь в Терминал строку целиком, Enter (она возьмёт самый свежий CSV из «Загрузок» и положит куда надо):

```
cd ~/Downloads && mv "$(ls -t *.csv | head -1)" /Users/admin/Claude/kodrosta-site/scripts/residents.csv && echo "готово"
```

### 4. Запустить скрипт

```
cd /Users/admin/Claude/kodrosta-site && python3 scripts/dump_group_members.py
```

Что он спросит:
- **api_id** и **api_hash** — вставь из шага 2 (спросит только в первый раз);
- **номер телефона** в формате `+79XXXXXXXXX` → в Telegram придёт **код** → введи его;
- если стоит облачный пароль (двухэтапная проверка) — введи его (на экране не отображается);
- покажет **список твоих групп с номерами** — введи номера нужных через запятую (или слово `все`).

Дальше скрипт сам всё сделает и напечатает итог. Файлы — в `scripts/out/`.

### Следующие запуски

Только шаг 4. Вход уже сохранён. Перед запуском обнови `residents.csv` (шаг 3), если база резидентов менялась.
