# Код Роста — сайт клуба

Одностраничник по ТЗ (`~/Desktop/ТЗ_сайт_Код_Роста.md`), задеплоен как Cloudflare Worker со статикой + серверной логикой в одном проекте.

## Структура
- `SUBSCRIPTIONS.md` — регламент продления: НЕДЕЛЯ / ДЕНЬ / СМС / ЗВОНОК, ФИНАЛ и правила статусов.
- `index.html` — вся страница (хиро → о клубе → цифры → зачем вступать → мероприятия → как вступить → контакты)
- `privacy.html` — политика обработки персональных данных (типовой шаблон, нужна юридическая проверка)
- `css/styles.css` — стили, фирменные цвета `#296EF7` / `#EB344A`
- `js/main.js` — рендер мероприятий, модалки форм, счётчики, генерация `.ics`
- `src/index.js` — Worker: раздаёт статику и обрабатывает `POST /api/submit` (пересылка заявок в Telegram)
- `wrangler.jsonc` — конфиг Worker'а (какой файл — точка входа, какая папка — статика)
- `.assetsignore` — список того, что не нужно раздавать как статику (сам Worker-код, конфиги)

## Что реализовано
- Форма заявки на вступление и форма записи на мероприятие (модалки), с honeypot-полем и минимальным временем заполнения (анти-спам)
- Отправка форм — `POST /api/submit` → бот шлёт сообщение в Telegram-группу клуба (см. ниже про настройку)
- Список мероприятий рендерится из массива `EVENTS` в `js/main.js`
- Кнопка «Скачать .ics» (все события) и «Добавить в Google Calendar» (на ближайшее/каждое событие)
- Анимированные счётчики в блоке «Цифры клуба»
- Exit-intent pop-up с оффером «−3000 ₽» для трафика с рекламного баннера (QR) — отдельный компонент `js/exit-popup.js` + `css/exit-popup.css`, настройки (скидка, промокод, сроки, тексты) — в начале `js/exit-popup.js` (`exitPopupConfig`)

## Настройка отправки заявок в Telegram (обязательно перед деплоем)
`src/index.js` берёт токен бота и id группы из секретов Worker'а — **не из кода**, чтобы токен не утёк через исходники страницы.

В Cloudflare: проект `kodrosta-site` → **Settings → Variables and Secrets** (или через `wrangler secret put`) — добавить:
- `BOT_TOKEN` — токен бота от @BotFather (Secret)
- `CHAT_ID` — id группы, куда слать заявки (Secret или Text)

Без этих переменных `/api/submit` будет отвечать ошибкой `not_configured`, и форма покажет пользователю подсказку написать в Telegram-менеджеру.

## Что нужно сделать перед запуском (открытые вопросы из ТЗ)
1. **Реальные мероприятия** — в `js/main.js` (массив `EVENTS`) сейчас мероприятия на август; обновляйте вручную по мере появления новых. Прошедшие события сайт скрывает автоматически.
2. **Фото резидентов** — по гайду нужны чёрно-белые фото в круглых масках; сейчас их нет (не было предоставлено), макет обходится без них геометрическими формами.
3. **Реквизиты клуба** — в футере и privacy.html стоят плейсхолдеры, нужно вписать реальные.
4. **Политика конфиденциальности** — типовой черновик, нужна проверка юристом.
5. **Хостинг** — деплой на Cloudflare Pages (Direct Upload), домен `codrosta.club` подключается через Custom domains в том же проекте.
6. **QR-код на рекламном баннере** — должен вести на `https://codrosta.club/?utm_source=banner&utm_medium=qr&utm_campaign=kod_rosta_3000` (или другие согласованные значения UTM). Для ИТ-парка использовать отдельную ссылку из раздела ниже.
7. **Цели в Яндекс.Метрике** — завести цели `qr_landing_open`, `exit_popup_triggered`, `exit_popup_closed`, `exit_popup_form_started`, `exit_popup_form_submitted`, `exit_popup_cta_clicked`, `discount_3000_issued`, `discount_3000_used` в интерфейсе счётчика 111842641 (код их уже отправляет через `ym(...,"reachGoal",...)`, но для отчётов цели нужно создать в самой Метрике).

## Как посмотреть
Просто открыть `index.html` в браузере, либо поднять локальный сервер:

```bash
cd kodrosta-site && python3 -m http.server 8080
```


## Реклама в ИТ-парке — аналитика (17 сентября 2026)

Подготовленная короткая ссылка: `https://codrosta.club/itpark`.
`_redirects` задаёт 302 на главную с `utm_source=itpark_rameev`, `utm_medium=qr`,
`utm_campaign=club_residents`, `utm_content=hall1_screen_v1`. Работает после деплоя.
Не менять назначение v1 для другого макета: для сравнения сделать отдельный путь и v2.

Общий `js/campaign-analytics.js` подключён на главной, страницах блога, privacy
и в шаблоне нового поста. Хранит последние UTM в sessionStorage вкладки,
сохраняет при внутренних переходах, заменяет при новом размеченном переходе.
Это источник заявки в данной вкладке, а не атрибуция всех будущих визитов.
Обычные формы передают метки в обработчик; они добавляются к сообщению менеджеру
и заметке заявки. Персональные данные в события Метрики не добавляются.

В кабинете счётчика 111842641 создать цели типа «Целевое событие», условие
«совпадает» (если уже существуют, не дублировать):

| Идентификатор | Название |
|---|---|
| qr_landing_open | Переход по QR (только utm_medium=qr) |
| apply_form_open | Открыта форма вступления |
| apply_form_success | Успешная заявка на вступление |
| event_form_open | Открыта запись на мероприятие |
| event_form_success | Успешная запись на мероприятие |
| manager_telegram_click | Переход к менеджеру в Telegram |

`form_submit` сохранена для прежних отчётов. Не складывать её с новыми целями:
это те же отправки. Цели success срабатывают только после успешного ответа API.
`exit_popup_form_submitted` — отдельная заявка на скидку, не оплата.
`discount_3000_used` в существующем коде означает отправку формы с промокодом,
а не подтверждённую оплату. Оплаты этим изменением не отслеживаются.

Отчёты → Источники → Метки UTM: сегмент по указанным source/campaign/content.
Добавить визиты, посетителей и конверсию/целевые визиты по apply_form_success,
event_form_success и manager_telegram_click. Вебвизор фильтровать тем же источником.
Число визитов не равно числу сканирований камеры или зрителей экрана.

Перед запуском проверить на боевом сайте редирект, сохранение UTM, получение
событий в Метрике, успешную отправку формы и сканирование QR в холле.
Локальные автоматические проверки используют заглушки: сообщения не отправляют.
